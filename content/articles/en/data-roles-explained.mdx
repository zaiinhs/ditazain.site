# Data Analyst, Data Engineer, and Data Scientist: Who Does What?

Three roles come up often in data work: Data Analyst, Data Engineer, and Data Scientist. What makes them different, and what does each one do? Let's break it down.

## Think of a Restaurant Kitchen

Before getting into the details, imagine a data team as a restaurant kitchen:

{{SOURCE_CODE_1}}

- **Data Engineer** is like the cook who prepares the ingredients.
- **Data Scientist** is like the specialist who creates recipes.
- **Data Analyst** is like the server who presents the meal to guests.

---

## What Is a Data Analyst?

A Data Analyst turns existing data into information and stories that other people can understand.

### A Day at Work

If you ran an online store, a Data Analyst might answer questions such as:

- How much did we sell today?
- Which product was bought most often?
- Where are our customers located?

{{SOURCE_CODE_2}}

### Tools

| Tool | Purpose |
|---|---|
| **Excel** | Simple analysis |
| **SQL** | Retrieving data from a database |
| **Tableau** | Interactive charts |
| **Power BI** | Business dashboards |
| **Python/R** | Further analysis |

### Skills

- **Basic math**: Understanding percentages and averages is enough to get started.
- **SQL**: Retrieving data.
- **Visualization**: Creating clear charts.
- **Communication**: Explaining findings to others.

---

## What Is a Data Engineer?

A Data Engineer builds and maintains the infrastructure that moves data between systems.

### Picture This

{{SOURCE_CODE_3}}

Data Engineers build roads for data. Without dependable data pipelines, analysts cannot do their work effectively.

### A Day at Work

- Build a pipeline that moves website data into a database.
- Make sure data from multiple sources can be combined.
- Optimize queries so analysts can work faster.

### Tools

| Tool | Purpose |
|---|---|
| **Python** | Common programming language |
| **Apache Spark** | Processing large datasets |
| **Airflow** | Orchestrating data workflows |
| **Snowflake/BigQuery** | Cloud data warehouses |
| **Docker/Kubernetes** | Managing containers |

### Skills

- **Programming**: Python, Scala, or Java.
- **SQL**: Transforming data.
- **Cloud**: AWS, GCP, or Azure.
- **System design**: Building scalable systems.

---

## What Is a Data Scientist?

A Data Scientist looks for patterns and makes predictions using statistics, programming, and business knowledge.

### How Is This Different from Data Analysis?

{{SOURCE_CODE_4}}

Analysts often explain what has happened. Data Scientists also try to predict what may happen next.

### A Day at Work

- Train a model that predicts customer churn.
- Recommend products to users.
- Segment customers based on their behavior.

{{SOURCE_CODE_5}}

### Tools

| Tool | Purpose |
|---|---|
| **Python** | Main language for data science |
| **TensorFlow/PyTorch** | Deep learning |
| **Scikit-learn** | Classical machine learning |
| **Jupyter Notebook** | Experiments and prototyping |
| **Statistics** | The foundations of modeling |

### Skills

- **Statistics**: Distributions and hypothesis testing.
- **Programming**: Python or R.
- **Machine Learning**: Regression and classification.
- **Domain knowledge**: Understanding the business problem.

---

## Side-by-Side Comparison

| Aspect | Data Analyst | Data Engineer | Data Scientist |
|---|---|---|---|
| **Goal** | Find insights in data | Build data infrastructure | Predict outcomes |
| **Output** | Reports, dashboards | Pipelines, ETL | ML models |
| **Typical tools** | SQL, Tableau | Python, Spark | Python, TensorFlow |
| **Core skills** | Communication, visualization | Engineering, cloud | Statistics, ML |
| **Starting level** | Beginner-friendly | Intermediate | Advanced |

## Which Role Fits You?

### Choose Data Analyst if:

- You enjoy reading charts and making reports.
- You like explaining findings to other people.
- You are new to working with data.

### Choose Data Engineer if:

- You enjoy building systems.
- You are interested in cloud and infrastructure.
- You like optimization and performance.

### Choose Data Scientist if:

- You enjoy math and statistics.
- You want to make predictions.
- You are ready to study machine learning.

## Conclusion

The three roles complement one another:

- **Data Engineers** build data foundations and pipelines.
- **Data Scientists** create models and predictions.
- **Data Analysts** explain the results so people can make decisions.

None is inherently better. Choose what interests you and start with the basics of SQL and Python.
