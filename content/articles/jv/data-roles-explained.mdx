# Data Analyst, Data Engineer, lan Data Scientist: Apa Bedane?

Ing donya data, ana telung peran sing kerep disebut: Data Analyst, Data Engineer, lan Data Scientist. Nanging apa bedane? Sapa nggarap apa? Artikel iki nerangake kanthi cara sing gampang dingerteni.

## Bayangna Kaya Pawon Restoran

Sadurunge mlebu rincian, bayangna tim data kaya pawon restoran:

{{SOURCE_CODE_1}}

- **Data Engineer** kaya juru masak sing nyiyapake bahan.
- **Data Scientist** kaya ahli rasa sing nggawe resep.
- **Data Analyst** kaya pelayan sing nerangake asil marang tamu.

---

## Apa kuwi Data Analyst?

Data Analyst ngowahi data sing wis ana dadi informasi lan crita sing bisa dingerteni wong liya.

### Tuladha Pekerjaan Saben Dina

Yen kowe duwe toko online, Data Analyst bisa nggoleki wangsulan kanggo pitakon:

- "Pira barang sing payu dina iki?"
- "Produk endi sing paling akeh dituku?"
- "Pelanggan kita saka ngendi wae?"

{{SOURCE_CODE_2}}

### Piranti sing Dienggo

| Piranti | Gunane |
|---|---|
| **Excel** | Analisis prasaja |
| **SQL** | Njupuk data saka database |
| **Tableau** | Nggawe grafik interaktif |
| **Power BI** | Dashboard bisnis |
| **Python/R** | Analisis luwih lanjut |

### Skill sing Dibutuhake

- **Matematika dhasar**: Ngerteni persentase lan rata-rata wis cukup kanggo miwiti.
- **SQL**: Njupuk data.
- **Visualisasi**: Nggawe grafik sing cetha.
- **Komunikasi**: Nerangake temuan marang wong liya.

---

## Apa kuwi Data Engineer?

Data Engineer nggawe lan ngrumat infrastruktur supaya data bisa mili saka siji panggonan menyang liyane.

### Bayangna Kaya Iki

{{SOURCE_CODE_3}}

Data Engineer kaya sing mbangun dalan kanggo data. Yen ora ana dalan sing apik, Data Analyst uga bakal angel kerja.

### Tuladha Pekerjaan Saben Dina

- Nggawe pipeline supaya data saka website mlebu database.
- Mesthekake data saka macem-macem sumber bisa digabung.
- Ngapikake kacepetan query supaya analisis luwih cepet.

### Piranti sing Dienggo

| Piranti | Gunane |
|---|---|
| **Python** | Basa pemrograman sing kerep dienggo |
| **Apache Spark** | Ngolah data skala gedhe |
| **Airflow** | Ngatur workflow data |
| **Snowflake/BigQuery** | Data warehouse ing cloud |
| **Docker/Kubernetes** | Ngatur container |

### Skill sing Dibutuhake

- **Pemrograman**: Python, Scala, utawa Java.
- **SQL**: Ngolah data.
- **Cloud**: AWS, GCP, utawa Azure.
- **System design**: Nggawe sistem sing bisa berkembang.

---

## Apa kuwi Data Scientist?

Data Scientist nggoleki pola ing data lan nggawe prediksi kanthi gabungan statistik, pemrograman, lan pengetahuan bisnis.

### Apa Bedane karo Data Analyst?

{{SOURCE_CODE_4}}

Data Analyst kerep nerangake apa sing wis kelakon, dene Data Scientist uga nyoba ngira apa sing bakal kelakon.

### Tuladha Pekerjaan Saben Dina

- Nggawe model kanggo prediksi pelanggan sing bakal mandheg nganggo layanan.
- Menehi rekomendasi produk kanggo pangguna.
- Nggawe kelompok pelanggan miturut prilakune.

{{SOURCE_CODE_5}}

### Piranti sing Dienggo

| Piranti | Gunane |
|---|---|
| **Python** | Basa utama kanggo data science |
| **TensorFlow/PyTorch** | Deep learning |
| **Scikit-learn** | Machine learning klasik |
| **Jupyter Notebook** | Eksperimen lan prototyping |
| **Statistics** | Dhasar kanggo nggawe model |

### Skill sing Dibutuhake

- **Statistik**: Distribusi lan uji hipotesis.
- **Pemrograman**: Python utawa R.
- **Machine Learning**: Regression lan classification.
- **Pengetahuan domain**: Ngerteni bisnis sing lagi diadhepi.

## Bandhingan Langsung

| Bab | Data Analyst | Data Engineer | Data Scientist |
|---|---|---|---|
| **Tujuan** | Nggoleki insight saka data | Nggawe infrastruktur data | Prediksi saka data |
| **Asil** | Laporan, dashboard | Pipeline, ETL | Model ML |
| **Piranti utama** | SQL, Tableau | Python, Spark | Python, TensorFlow |
| **Skill** | Komunikasi, visualisasi | Engineering, cloud | Statistik, ML |
| **Tingkat wiwitan** | Gampang kanggo pamula | Menengah | Luwih lanjut |

## Milih Peran Sing Cocog

### Pilih Data Analyst yen:

- Kowe seneng maca grafik lan nggawe laporan.
- Kowe seneng nerangake temuan marang wong liya.
- Kowe lagi miwiti sinau data.

### Pilih Data Engineer yen:

- Kowe seneng nggawe sistem.
- Kowe tertarik karo cloud lan infrastruktur.
- Kowe seneng optimasi lan performa.

### Pilih Data Scientist yen:

- Kowe seneng matematika lan statistik.
- Kowe kepengin nggawe prediksi.
- Kowe siap sinau machine learning.

## Kesimpulan

Telung peran iki saling nglengkapi ing tim data:

- **Data Engineer** nggawe dhasar lan alur data.
- **Data Scientist** nggawe model lan prediksi.
- **Data Analyst** nerangake asil data supaya bisa dienggo njupuk keputusan.

Ora ana sing luwih apik tinimbang liyane. Pilih miturut minatmu, banjur miwiti saka SQL lan Python dhasar.
