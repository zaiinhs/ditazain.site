# Ngapikake Performa Aplikasi Web

Performa penting kanggo pengalaman pangguna. Ayo deleng teknik optimasi sing praktis.

## Core Web Vitals

- **LCP** (Largest Contentful Paint): kurang saka 2,5 detik.
- **FID** (First Input Delay): kurang saka 100 milidetik.
- **CLS** (Cumulative Layout Shift): kurang saka 0,1.
