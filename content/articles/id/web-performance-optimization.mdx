# Optimasi Performa Aplikasi Web

Performa penting untuk pengalaman pengguna. Mari bahas teknik optimasi yang praktis.

## Core Web Vitals

- **LCP** (Largest Contentful Paint): kurang dari 2,5 detik.
- **FID** (First Input Delay): kurang dari 100 milidetik.
- **CLS** (Cumulative Layout Shift): kurang dari 0,1.
